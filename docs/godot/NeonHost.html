NeonHost NeonHost.gd

extends RefCounted

Manages a game session as the host, connected through a NeonRelay.

Create a NeonHost, register callbacks, then call start_and_run (blocking) or start followed by a manual loop calling process_packets. The host handles client connection, reconnection, session config delivery, and ACK tracking.

funcstart_and_run()

Starts the host and blocks in the processing loop until stop is called.

Equivalent to calling start then looping process_packets. Run on a dedicated thread.

funcstart() -> bool

Connects to the relay and registers this session without blocking.

Returns true on success. After this returns, call process_packets in a loop to handle incoming connections.

funcstop()

Gracefully shuts down the host.

Waits up to NeonConfig.host_graceful_shutdown_timeout_ms for pending ACKs, then sends a disconnect notice to all clients and closes the socket.

funcis_running() -> bool

Returns true if the host is connected and processing.

funcprocess_packets()

Drains all pending packets from the socket without blocking.

Called automatically by start_and_run. Can be called manually if you manage the loop yourself.
