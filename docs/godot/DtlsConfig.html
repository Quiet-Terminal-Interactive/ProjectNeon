DtlsConfig DtlsConfig.gd

extends RefCounted

TLS/DTLS configuration for encrypted relay connections.

Use the static constructors rather than instantiating directly. Pass the result to [member NeonConfig.dtls_config]. If no DtlsConfig is provided, connections use plain UDP without encryption.
