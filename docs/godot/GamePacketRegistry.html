GamePacketRegistry GamePacketRegistry.gd

extends RefCounted

Registry of game-specific packet type IDs, names, and descriptions.

Assign an instance to [member NeonHost.packet_registry] to have the host broadcast the registry to each client when they connect. Clients receive it via [member NeonClient.packet_registry_callback].

All game packet IDs must be >= 0x10. IDs below that are reserved for the Neon protocol.
