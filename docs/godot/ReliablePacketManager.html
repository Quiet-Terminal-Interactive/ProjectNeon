ReliablePacketManager ReliablePacketManager.gd

extends RefCounted

Tracks outbound reliable packets and retransmits them on timeout.

Also provides duplicate detection for inbound packets using sequence number comparison. Call send_reliable instead of sending directly. Call on_ack_received when ACK packets arrive, and check_timeouts once per tick to retransmit.
