NeonConfig NeonConfig.gd

extends RefCounted

Shared configuration for NeonClient, NeonHost, and NeonRelay.

Create an instance and pass it to the constructor of whichever class you are configuring. All timing values are in milliseconds. Properties not relevant to a given class are ignored.
