NeonClient NeonClient.gd

extends RefCounted

Connects to a game session through a NeonRelay as a client.

Create a NeonClient, register callbacks, then call connect to join a session. Call run on a background thread to process incoming packets and maintain pings. Use send_packet to send game-specific packets to other peers.

funcrun()

Blocking packet processing loop. Call on a background thread after connect.

Processes packets and sends keepalive pings until stop is called.

funcstop()

Sends a disconnect notice and stops the run loop.

funcis_running() -> bool

Returns true if the run loop is active.

funcprocess_packets()

Drains all pending packets from the socket without blocking.

Called automatically by run. Can also be called manually if you manage the loop yourself instead of calling run.
